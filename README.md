# ✨ ALL IN ONE x IMRAN

A modern, dark-mode personal portfolio & digital hub built with pure **HTML5, CSS3, and Vanilla JavaScript**—featuring a liquid glass UI, 120FPS smooth animations, and interactive widgets.

🌐 **Live Website:** [https://mdimr4nbd.github.io/dev_imranxbd/](https://mdimr4nbd.github.io/dev_imranxbd/)

---

## 🚀 Key Features

- **🎨 12 Dynamic Dark Themes:** Instant theme switcher (`Emerald`, `Cosmic`, `Pure Black`, `Black Gold`, `Black Red`, `Neon Black`, `Aurora`, `Ocean`, and more) with local storage persistence.
- **🎵 Liquid Glass Music Player:** Slim, compact custom audio widget with play/pause, shuffle, seek bar, mute toggle, and multi-track support.
- **💎 Free Fire UID Top-Up Modal:** Built-in interactive diamond package selector with direct WhatsApp order checkout.
- **💻 Live Status Code Box:** Seamless, flicker-free GPU-accelerated scrolling code preview with real-time clock, active theme, and channel updates.
- **⚡ 120FPS Performance:** Lightweight, zero-dependency architecture with canvas falling streak particles and smooth scroll-reveal animations.
- **📱 Fully Responsive:** Optimized for mobile, iOS, and desktop screens with safe-area inset support.
